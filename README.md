#  1. From Air to Balloon

**Rapid Games Prototyping - Week 1**

### [Play Demo on Itch.io](https://jesuspinarte.itch.io/from-air-to-balloon)

## Overview

A physics-based prototype focused on juice and feel. Players must manage air pressure and buoyancy to navigate a fragile balloon through a series of obstacles. This project explored the fundamentals of Unity's Physics Engine and player feedback (game feel).

## Technical Implementation
- **Custom Buoyancy Physics:** Developed a manual force-calculation system to simulate air resistance and lift.
- **Dynamic Scaling:** Real-time mesh scaling linked to internal "pressure" variables.
- **Collision Matrix:** Optimised collision layers to handle delicate interactions between the balloon and sharp environment hazards.

## Controls
- **Space/Left Click:** Inflate / Add Lift.
- **WASD/Arrows:** Subtle directional movement.
